# Соответствие заданию лабораторного практикума №3

Тема из предоставленного задания: **«Построение IDEF0 и UML/ER-диаграмм»**. Использована библиотечная система из предыдущей лабораторной с расширением до полноценного обслуживания читателей.

| Требование | Выполнение |
| --- | --- |
| Предметная область с 12–20 сущностями | 16 сущностей в `model/entities.json`, ER и SQL |
| Описание области в 5–10 предложениях | 8 предложений в отчёте |
| Контекст A-0 | `diagrams/idef0/A-0.svg` |
| Уровень A0: 3–6 основных функций | Четыре функции A1–A4 |
| Декомпозиция каждой функции A0 минимум на один уровень | A11–A13, A21–A23, A31–A33, A41–A43 |
| Входы, выходы, управление, механизмы | I/O/C/M на всех шести страницах; полные подписи в легендах |
| UML-классы или ER с атрибутами и кардинальностями | ER, 16 сущностей, 19 связей; PK/FK/UQ и ключевые бизнес-атрибуты |
| Описание структуры данных в 1–2 абзацах | Два абзаца в разделе отчёта «Структура данных» |
| Два–три основных сценария | Регистрация и бронирование; выдача; возврат и оплата |
| Отчёт: титульник, цель, описание, диаграммы, данные, сценарии, вывод | `reports/ЛР03.docx`, 15 страниц |
| Сохранение результатов и исходников | DOCX, draw.io, PlantUML, SVG, PNG, JSON, SQL, скрипты и результаты проверок |

Матрица фиксирует содержание приложенного задания без воспроизведения его полного текста. SQL-схема, сценарии и автоматические проверки дополнительно подтверждают согласованность ER-модели и выбранных правил обслуживания.
